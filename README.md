# MATLAB 手写数字 CNN 分类

一个从图像读取、网络训练到分类评估的手写数字识别练习。输入为 MATLAB 自带 `DigitDataset` 中的数字图像，输出为 0–9 十个类别；重点是把完整训练流程写成可查看、可运行的脚本。

## 完成了什么

提供 CPU 与 GPU 两份脚本，均包含数据筛选、训练集划分、两层卷积网络、训练和预测。每类最多使用 100 张图像，按 80%/20% 随机划分，默认训练 2 个 epoch。

| 运行输出 | 用途 |
| --- | --- |
| 训练进度窗口 | 观察损失与准确率随训练变化 |
| 分类准确率与混淆矩阵 | 查看整体分类情况及容易混淆的数字类别 |
| 16 张预测样本 | 对照原图和预测标签，直接检查识别效果 |

当前公开成果是两份训练与评估脚本，未附模型权重、训练日志或结果截图。旧版说明曾记录一次 CPU 准确率为 88.50%，但缺少对应随机划分与输出文件，因此不将该数值作为可复核的性能结论；本次文档整理未重新训练。

## 实现思路

```text
DigitDataset → 按类别选取图像 → 80% 训练 / 20% 留出
→ 调整为 28×28 → CNN 训练 → 分类预测 → 准确率、混淆矩阵、样本图
```

网络依次为：3×3 卷积（8 通道）、批归一化、ReLU、2×2 最大池化、3×3 卷积（16 通道）、批归一化、ReLU、10 类全连接层与 Softmax。优化器使用 SGDM，初始学习率为 0.01。

两份脚本的区别如下，不能直接用它们得出 CPU/GPU 加速比：

| 设置 | CPU 版本 | GPU 版本 |
| --- | --- | --- |
| 输入 | 28×28 单通道灰度图 | 灰度图复制为 28×28 三通道 |
| 批大小 | 128 | 64 |
| 执行环境 | CPU | CUDA GPU |

20% 留出数据同时用于训练过程中的验证和最后的分类评估，没有另设独立测试集；脚本也未固定随机种子。当前适合学习训练流程，尚不足以支持严格的泛化性能比较。

## 公开内容与运行方法

- [CPU 训练与评估脚本](src/cnn_cpu.m)
- [GPU 训练与评估脚本](src/cnn_gpu.m)

需要 MATLAB、Deep Learning Toolbox、Image Processing Toolbox，以及 MATLAB 安装目录内的 `DigitDataset`。GPU 版本还需要 Parallel Computing Toolbox 与兼容的 CUDA GPU；其实际 GPU 运行尚未验证。

在 MATLAB 中将当前目录切换到仓库根目录，选择一个版本运行：

```matlab
run("src/cnn_cpu.m")
% 或使用 GPU 版本：
run("src/cnn_gpu.m")
```

脚本会在窗口中展示训练和预测结果，在命令行输出准确率；不会自动保存权重或图表。数据集由 MATLAB 提供，仓库不重复分发。脚本使用 `trainNetwork` 与 `classificationLayer`，需要所用 MATLAB 版本支持这些接口。
